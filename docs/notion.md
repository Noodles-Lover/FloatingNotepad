# Notion 同步设计

浮笺与本机 Notion（Internal Integration）之间的双向同步：速记、待办、日程三个
数据库，手动触发，One Notion API，密钥只存本机。

## 数据落点

- 容器页下三个数据库：**浮笺 · 速记 / 浮笺 · 待办 / 浮笺 · 日程**。
  缺哪个在同步开头自动建哪个（`notion.rs` 的 `ensure_databases`），老库缺属性时
  用幂等 PATCH 补齐，所以没有单独的「建数据库」按钮。
- 同步配置（密钥、容器页 ID、三个库 ID）存在本地 SQLite 的 meta 表，
  不离开本机；日志里只记「密钥已填/空」，绝不落密钥原文。

## 三个核心概念

| 概念 | 是什么 | 回答什么问题 |
|---|---|---|
| **锚点** | Notion 页面上的「本地ID」属性（数字，速记/日程用）或「本地UID」（富文本，待办 id 是 UUID 字符串、数字属性放不下） | 这页对应本地哪条 |
| **签名** | 内容关键属性的原样拼接串（`note_sig` / `todo_sig` / `plan_sig`），只做相等比较所以不哈希 | 这条数据现在长什么样 |
| **快照** | 映射表里存着的上次同步时的双侧签名 | 上次之后谁动过 |

## 映射表

本地 SQLite 的 `notion_sync` 表（`db.rs`）：

```
collection | local_id | page_id | local_sig | remote_sig
```

`local_id ↔ page_id` 是配对关系，两个签名是双侧快照。它是整个同步的**唯一记忆**。

## 一轮同步的判定

每轮先拉取 Notion 三库全部页面，按锚点配对，然后：

**变更（两边都在）**

| 情况 | 动作 |
|---|---|
| 本地签名 ≠ 本地快照 | 本地动过 → **推**（本地为准），快照更新为新签名 |
| 远端签名 ≠ 远端快照 | 远端动过 → **拉**（远端为准） |
| 两边都动过且签名不同 | 计入 `conflicts`，**本地为准**推上去 |
| 两边都动过但签名收敛一致 | 不算冲突，只更新快照 |

**存在性（一边没了）**

| 情况 | 动作 |
|---|---|
| 本地没了、Notion 还有 | 归档 Notion 页，删映射 |
| Notion 没了、本地还有 | 删本地条目，删映射 |
| 两边都没了 | 只清映射 |

**新建**

- 本地有、无映射 → 建页，锚点随建页写入。
- 页面无锚点（手机端/网页端新建）→ 导入本地，**立刻回写锚点**——
  否则下一轮认不出这页是自己的，会被再导入一次（历史上待办重复就是这个坑）。

**已知取舍：删除无条件获胜。** 一边删除时，另一边的未同步编辑会被直接跟随删除，
不进冲突计数。要做到「编辑 vs 删除」也算冲突需要引入墓碑（tombstone）记录
"这是删除不是丢失"，当前没做。

## 重置同步

映射表是唯一记忆，所以修复映射错乱的办法是**失忆重建**：

1. 归档 Notion 三库的全部页面（archive，可从回收站恢复，不是硬删）；
2. 清空映射表。

之后点同步：所有本地条目因无映射被当新建，逐条建页写锚点，按本地现状重建。
本地数据全程不动。注意：Notion 端手工新建、还没导入的条目也会被一起归档掉。

## 日期与时刻

- 日程时间并入 Notion 的**日期属性**：`2026-10-05T09:00:00+08:00`。
  Notion 要求带时刻的日期必须带时区（`GetTimeZoneInformation` 算本地偏移），
  带上后 Notion 自动开启「包含时间」，能按点提醒。
- 回读时把带秒和时区的串归一化回 `HH:MM` 存本地，签名比对不受影响。
- 不再写「时刻」文本属性（老库该列仍在，代码不依赖）；周常日程没有固定日期，
  远端写成「下一次到期日」。

## UI 与状态

- 入口：速记面板头栏的 Notion 按钮 → 独立覆盖层 `NotionPanel`。
- 面板状态（输入、执行中提示、结果消息）放在模块级单例 `useNotionSync`：
  面板收起会卸载组件，但同步是后台动作，状态必须活过一次「收起再打开」。
- 串行守卫：同一时刻只允许一个 Notion 动作（保存/同步/重置互斥）。
- 同步成功后 Rust 发 `notion-synced` 事件，`useEntityData` 与 `usePlans`
  重载数据——拉回的新条目立刻出现在界面上，不用重启。

## 日志

命令入口统一留痕（`lib.rs`，标签 `[notion]`）：

- `配置已保存: 密钥已填, 容器页=<ID>`（密钥原文不进日志）
- `建库完成` / `建库失败: <Notion 原始返回>`
- `同步完成: 推 X / 拉 X / 删 X / 冲突 X` / `同步失败: <Notion 原始返回>`
- `同步已重置: 归档 N 页` / `重置失败: ...`

## 已知限制

- 只有手动同步，没有自动轮询/防抖推送（讨论过「本地改动防抖 5 秒自动推」，
  未实现）。
- 删除优先于编辑（无墓碑）。
- 列宽、视图（筛选/排序/布局）不受 Notion API 支持，只能在 Notion 界面手动调。
