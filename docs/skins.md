# 皮肤制作指南

皮肤是 `public/skin/` 下的一个文件夹。放入图片后重启应用即可被发现，无需登记清单。

本文面向想自制皮肤的场景。若只想换皮肤，见 [README 的「添加皮肤」](../README.md#添加皮肤)。

---

## 目录结构

```
public/skin/
├─ default/           # 出厂默认，未选择过时自动使用
│  └─ widget.png
├─ ai_anime_girl/     # 变化模式示例
│  ├─ idle.png
│  └─ hover.png
└─ my-skin/           # 你新增的皮肤，文件夹名即皮肤名
   └─ widget.png
```

文件夹名会直接显示在皮肤选择面板里，所以取个能看懂的名字。

---

## 两种模式

应用按**文件名**判定模式，这是硬性约定：

| 模式 | 判定条件 | 行为 |
| --- | --- | --- |
| **滑动**（slide） | 存在 `widget.png` | 整颗挂件贴边停靠，隐藏态用 CSS 把图滑出半截，悬停时整颗伸出 |
| **变化**（transform） | 同时存在 `idle.png` 与 `hover.png` | 整颗停靠不动，靠切换两张图表现半掩与伸出 |

同一文件夹里两种都放时，`widget.png` 优先，判定为滑动模式。
三者都没有的文件夹会被静默忽略。

### 选哪种

- **滑动**：素材只有一张，或希望"探出"动作由程序统一控制。当前默认皮肤采用此模式。
- **变化**：想精确控制半掩与伸出两个姿态的造型差异（比如角色换姿势）。素材需要两张。

---

## 图片规格

**必须**：PNG 格式、透明背景。挂件会浮在任意界面之上，不透明会露出方块底色。

**尺寸**：无硬性要求，图片会按设置里的「挂件尺寸」等比缩放后居中放进正方形容器，超出部分不会裁剪（`object-fit: contain`）。

建议按挂件最大可能尺寸（默认 56，设置里可调到 200）准备素材，避免放大后模糊：

| 模式 | 建议 | 参考现有皮肤 |
| --- | --- | --- |
| 滑动 | 单边 300~800 px | `default/widget.png` 为 750×250 |
| 变化 | 单边 300~800 px，两张图**尺寸一致** | `ai_anime_girl` 为 271×384 / 270×380 |

### 构图要点

**滑动模式——内容靠右。**
贴右侧时直接靠右停靠；贴左侧时整图会水平翻转，因此素材按"内容集中在右侧"来画，翻转后视觉上才会朝屏幕内侧探出。

**变化模式——两张图主体位置对齐。**
切换是交叉淡入淡出，若两张图的主体位置或尺寸差异明显，切换时会有跳动感。保持画布尺寸一致、主体在同一位置最稳妥。

### 半掩态的表现

挂件隐藏时只露出约一半区域（贴边方向的一半被推出屏幕外）。

- 滑动模式：由程序滑出，素材本身画"完整形态"即可。
- 变化模式：`idle.png` 需要**自己画出半掩的观感**——把内容集中在一侧，让露出屏幕的那半边承载主要视觉。

## 安装与启用

1. 把文件夹放进 `public/skin/`
2. 重启应用（`npm run tauri:dev`）
3. 点击挂件打开面板 → 右上角调色板图标 → 选择皮肤

选择会存入 localStorage，跨启动保留。

---

## 打包后的皮肤目录

打包安装版里，皮肤位于应用资源目录的 `skin/` 下（由 `tauri.conf.json` 的 `bundle.resources` 映射 `../public/skin` → `skin`）。

在已安装版本上添加皮肤，把文件夹放进该 `skin/` 目录后重启即可。

---

## 故障排查

**新皮肤没出现在列表里**

- 文件名是否严格为 `widget.png` / `idle.png` / `hover.png`（小写）
- 变化模式必须两张图**同时存在**，只有其中一张会被忽略
- 文件夹名是否以 `.` 开头（会被视为隐藏目录跳过）
- 是否重启了应用

**皮肤能选但图不显示**

- 图片是否为有效 PNG（扩展名改成 `.png` 的其他格式无效）
- dev 模式下 Vite 可能对不存在的图片返回 HTML，导致误判为存在；重启即可

**所有皮肤都读不到**

会回落到内置的 `default` 皮肤。检查 `public/skin/` 目录是否存在，以及打包时资源是否被正确包含。
