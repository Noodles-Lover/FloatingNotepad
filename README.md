# 浮笺 (FloatingNotepad)

桌面悬浮记事本：贴边收纳，鼠标靠近自动弹出，点击展开速记面板，输入即存。

技术栈：Tauri v2 + React + Vite + SQLite。

---

## 功能特性

- **贴边悬浮挂件**：默认贴屏幕右沿只露一条边，鼠标靠近滑出，离开自动收起。
- **速记面板**：多标签页（单击切换、双击重命名、拖拽排序、`+` 新增），输入即存。
- **待办管理**：多分类待办，支持优先级、完成态、备注；完成项自动沉底。
- **穿透模式**：挂件只剩视觉效果，点击穿透到后方窗口、不抢焦点，适合全屏场景。
- **皮肤系统**：`public/skin/` 下每个文件夹即一套皮肤，自动发现。
- **设置面板**：挂件尺寸、面板宽高、自动收起延时、闲置不透明度等，即时生效。
- **系统托盘 / 右键菜单**：显示隐藏挂件、切换穿透模式、退出。
- **多显示器**：窗口定位基于当前显示器真实尺寸，多屏/热插拔不跑出屏幕。

## 下载安装

### 获取安装包

从 Releases 下载最新的 `FloatingNotepad_x.x.x_x64-setup.exe`：

<https://github.com/Noodles-Lover/FloatingNotepad/releases>

### 安装

1. 双击运行安装包
2. 若出现「Windows 已保护你的电脑」，点击**更多信息 → 仍要运行**
   （应用未做商业代码签名，此为系统对未知发布者的常规提示）
3. 按向导完成安装。默认安装到当前用户目录（`%LOCALAPPDATA%\FloatingNotepad\`），
   不需要管理员权限

### 运行要求

- Windows 10 1809+ / Windows 11
- **WebView2 运行时**：Win11 一般自带；若启动后无任何反应，先从微软官网安装 WebView2 再重试

### 数据存在哪

速记与待办保存在：

```
%APPDATA%\com.floatingnotepad.app\notes.db
```

**备份或迁移**：复制整个 `com.floatingnotepad.app` 文件夹即可。
也可在设置面板点击「打开数据文件夹」直接定位到该目录。

数据存于用户目录而非安装目录，因此**卸载应用不会删除你的速记与待办**。

### 更新

方式一（推荐）：打开设置面板 → 「检查更新」，应用会自动下载安装，
完成后点「重启应用」生效。

方式二：到 Releases 下载新版本安装包覆盖安装，数据不受影响。

> 更新包使用 Tauri 自带的更新签名（自签密钥，非商业证书）验证完整性，
> 可防止更新被篡改；它不能消除安装时的 SmartScreen 提示，两者是不同机制。

## 使用说明

### 挂件

启动后贴右沿只露一条边；鼠标移到该区域滑出；点击展开速记面板；**拖动可切换贴附到左/右沿**。

### 面板

- 按 `Esc` 或点右上角 `×` 收起；鼠标移开一段时间后自动收边。
- 右上角按钮依次为：固定面板、皮肤、设置。
- 固定后不再自动收起，只能手动关闭。

### 托盘与右键菜单

| 入口 | 可用操作 |
| --- | --- |
| 挂件右键 | 隐藏挂件、穿透模式、退出 |
| 系统托盘 | 显示挂件、隐藏挂件、穿透模式（勾选同步）、退出 |

托盘「隐藏挂件」后需从托盘「显示挂件」恢复。

### 穿透模式

开启后挂件只保留视觉效果，鼠标点击直接穿透到后方窗口，本应用也不会抢焦点。

穿透期间挂件不接受任何交互，因此鼠标靠近时会在挂件旁显示一个**解锁按钮**，点击即退出穿透。解锁按钮会在鼠标离开后按「自动收起延时」隐藏。

## 添加皮肤

皮肤就是 `public/skin/` 下的一个文件夹，放入 PNG 即可，应用启动时自动发现，无需登记。

1. 在 `public/skin/` 下新建文件夹，**文件夹名即皮肤名**
2. 按下面任一模式放入图片：

   | 模式 | 需要的文件 | 效果 |
   | --- | --- | --- |
   | 滑动 | `widget.png` | 单张图，隐藏时滑出半截，悬停时整颗伸出 |
   | 变化 | `idle.png` + `hover.png` | 两张图切换：半掩态一张，伸出态一张 |

3. 重启应用，在挂件 → 面板右上角调色板图标 → 皮肤里选择

文件夹内既无 `widget.png` 也无 `idle.png`/`hover.png` 时会被忽略。
名为 `default` 的皮肤为出厂默认，未选择过时自动使用。

详细说明可见 **[public/skin/README.txt](public/skin/README.txt)**。

## 快速开始（开发）

### 环境要求

- **Node.js** ≥ 18
- **Rust** 工具链（stable）：<https://rustup.rs>
- **Visual Studio 2022 Build Tools**：需勾选「使用 C++ 的桌面开发」工作负载
- **WebView2 运行时**：Win11 一般自带，没有则从微软官网安装

### 运行

```powershell
npm install
npm run tauri:dev
```

首次会编译 Rust 侧（几分钟），之后快很多。

> `npm run dev` 只启动前端（Vite），没有窗口与系统托盘，仅用于调 UI。

### 打包

```powershell
npm run tauri:build
```

## 目录结构

```
floating-notepad/
├─ docs/                   # 文档
├─ public/
│  └─ skin/                # 皮肤目录（每子目录一套）
├─ src/                    # React 前端
│  ├─ main.tsx             # 入口（按窗口 label 分流渲染挂件或解锁按钮）
│  ├─ App.tsx              # 状态机 + 各功能协调
│  ├─ App.css
│  ├─ lib/                 # 窗口控制、配置、皮肤、数据库封装等
│  ├─ components/
│  │  ├─ FloatingWidget.tsx  # 悬浮挂件
│  │  ├─ NotePanel.tsx       # 速记与待办面板
│  │  ├─ TabBar.tsx          # 标签栏（速记标签页与待办分类共用）
│  │  ├─ LockView.tsx        # 穿透解锁按钮（独立窗口）
│  │  ├─ SkinPanel.tsx       # 皮肤选择
│  │  ├─ SettingsPanel.tsx   # 设置
│  │  └─ ConfirmDialog.tsx   # 通用确认框
│  └─ LOGIC.md
└─ src-tauri/              # Rust 后端
   ├─ capabilities/        # 前端能力权限
   ├─ permissions/         # 自定义命令权限
   ├─ src/
   │  ├─ lib.rs            # 命令、穿透模式、解锁锁、鼠标轮询、系统托盘
   │  └─ db.rs             # SQLite
   └─ LOGIC.md
```
