悬浮挂件皮肤目录
================

每个子文件夹都是一个“材质包”，文件夹名即材质名（直接展示，无需额外 label）。
本目录只存放图片素材；可用材质包由应用运行时自动读取（通过 Rust 命令列出
skin/ 下的子文件夹，再对每个文件夹探测图片文件名来判断模式），无需手动登记清单。

新增一个材质包的步骤：
  1. 在 skin/ 下新建文件夹，文件夹名即材质名，例如 skin/fox/
  2. 按下面两种模式之一放入图片（文件名硬性要求）：
       - 滑动模式（单张图，用 CSS 滑出半掩）：widget.png
       - 变化模式（两张图切换）：idle.png（半掩态） + hover.png（伸出态）
  3. 无需其他配置，重启应用即可被自动发现并列出。

文件名约定（硬性要求，应用据此判定模式）：
  widget.png 滑动模式的单张图（半掩/伸出由 CSS 滑出表现）
  idle.png   变化模式的“半掩态”图
  hover.png  变化模式的“伸出态”图

注意：
  - 一个文件夹里若有 widget.png 则判定为滑动模式；有 idle/hover 则判定为变化模式；
    若三者皆无则该文件夹被忽略。
  - 图片会按配置中的 widgetSize 等比例缩放，并靠贴附边对齐（贴左靠左、贴右时翻转后视觉靠右）。
  - 滑动模式下单张 widget.png 用 CSS 滑出半掩（隐藏态滑出半截，hover 时整颗伸出）。
  - 变化模式下隐藏态整颗停靠（由图片自身表现半掩），不做 CSS 滑出。
  - 文件夹名 default 为出厂默认皮肤；未选择过时自动使用它。

修改后重新运行（npm run tauri:dev）即可生效。
